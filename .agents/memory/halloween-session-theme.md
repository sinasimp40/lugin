The owner approved the Spectral Glass design, including the transparent 3D ghost moving end to end and back, as the production **Halloween** session theme. Keep the original look available as **Default**.

Halloween is a shop-wide look: apply the same selection to the lock screen, login, registration, curfew-hours screen, and session view—not only the session bar.

**Why:** The owner explicitly requested matching Halloween designs on all these screens, including in Auto Shutdown's Windows executable.

**Why:** After approving the animated mockup, the owner requested Default/Halloween choices in Auto Shutdown's admin panel, shared through Denfi Points because the shop's PCs use a diskless setup.

**How to apply:** Denfi Points owns the selection; updated kiosks automatically apply confirmed server changes without interrupting sessions. Preserve original controls, full usernames, betting animations, and the logo effect. Retain only assets required by the production theme; the owner requested removal of mockups to reduce file size.

Online PCs must update both their visible theme and the admin's active selection without pressing **Reload Selection**. Unsaved choices must remain unpublished.

**Why:** The owner clarified that needing Reload Selection on other online PCs is a bug, not the intended workflow.

**How to apply:** Treat Reload Selection as manual recovery only. Check automatic updates, disconnection retention, and reconnect recovery without calling the admin reload action.
