---
name: Session overlay footprint
description: Why compact status controls and button-opened popups matter for Session Mode design
---

Session Mode is an overlay on a player's game, not a conventional dashboard. Preserve an unobtrusive always-visible session display and open tools only when requested as small popups. The user rejected broad bottom decks and tall sidecars even when they included all the desired tools.

**Why:** The user chose the existing compact layout specifically because it does not cover much of the game screen. A visually polished alternative that occupies a large area still fails the main requirement.

The user also rejected compact neon/tactical mockups as ugly and asked specifically for a premium look. "Gaming" is the product context, not a request for dense HUD decoration or glowing arcade styling.

**How to apply:** In future Session Mode design explorations, judge each option by its on-screen footprint both closed and open. Keep Betting Games, Quick Order, Attendance, and Ranking reachable without letting their shared navigation become a permanently wide panel. Favor restrained, premium gaming-native material and readable controls over busy graphics, tiny labels, or simulated game scenery.
