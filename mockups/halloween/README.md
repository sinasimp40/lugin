# Halloween session theme exploration

These are isolated design-only copies of the existing `public/session.html`.
Do not change production session files when editing these mockups.

The original markup, scripts, IDs, balance protection, logo cycle, and preview-mode
interactions are retained. Only theme CSS and isolated preview sizing helpers differ.
Real purchases, payouts, login, logout, and shared feeds are not connected.

Artwork: transparent 3D PNG previews downloaded from Vecteezy search results.
Original URLs are recorded by the build script. Licensing must be checked before
using the selected artwork in a distributed Windows app.

Run `node scripts/build-halloween-mockups.cjs` to regenerate the self-contained
browser comparison at `public/halloween-mockups/index.html`.
